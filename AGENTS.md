# Minhas Trilhas — instruções para agentes de IA

Antes de agir neste repositório:

1. Leia [as regras de trabalho](ai/rules/workflow.md).
2. Leia [o índice de instruções para IA](ai/README.md) e abra os módulos
   aplicáveis antes de editar. Reavalie a seleção se o escopo mudar.
3. Ao preparar uma pull request, leia e execute a skill
   [prepare-pull-request](ai/skills/prepare-pull-request/SKILL.md).

Os links são instruções de leitura, não imports automáticos. Resolva cada
referência relativa ao arquivo que a contém. Se uma referência obrigatória
estiver ausente, informe a lacuna antes de executar a ação dependente.

`ai/` contém instruções diretas para IA; [docs/](docs/README.md) contém a
documentação compartilhada com desenvolvedores. Mantenha cada regra em sua
fonte e use referências nos demais arquivos.
